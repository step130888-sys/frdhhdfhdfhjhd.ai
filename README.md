# 🌲 Координационная платформа студенческого медиацентра «СМС СГТУ» (Vue 3 Edition)

Полнофункциональная закрытая веб-платформа для координации команды студенческого медиацентра (Фотографы, Дизайнеры, Видеографы, Моушн-дизайнеры, SMM, Руководство, Администраторы).

---

## 🛠 Стек технологий
- **Фронтенд:** Vue 3 (Composition API, `<script setup>`), Vue Router 4, Tailwind CSS 3, Vite 5.
- **Бэкенд:** Express.js REST API (Node.js 20+).
- **База данных:** SQLite 3 в режиме WAL (`PRAGMA journal_mode = WAL;`) с 9 индексами и отсутствием N+1 запросов.
- **Интеграции:** Telegram Bot (Long polling, inline-оценки [10..6] и [🔄 На доработку], команды) и VK Bot (Long Poll, интерактивная клавиатура, авторезолв через `resolveScreenName`).
- **Стилизация:** Cosmic Dark Glass Theme, адаптивный интерфейс, индикаторы онлайна в реальном времени.

---

## 🏛 6 Цехов и направления
1. **«Фото»** — репортажи, фотосессии, протокольная съемка
2. **«Дизайн»** — афиши, баннеры, графическое оформление постов
3. **«Видео»** — видеографы, рилсмейкеры, операторы, монтаж
4. **«Моушен»** — 2D/3D анимация, заставки, плашки, графика
5. **«СММ»** — тексты, контент-планы, копирайтинг
6. **«Звук»** — запись звука, сведение, подкасты, саунд-дизайн

## 👥 Иерархия доступа (Уровни 1..4)
1. **Уровень 1 (Участник направления):**
   - Просмотр и взятие свободных задач своего цеха (`open` $\to$ `in_progress`).
   - Сдача выполненной работы на проверку (`review`) с файлом или внешней ссылкой.
   - Право создания задач выключено по умолчанию (включается админом через флаг `can_create_tasks = 1`).
2. **Уровень 2 (Глава направления / Цеховик):**
   - Управление задачами своего цеха, создание задач в свой цех.
   - **⚡ Принудительное назначение задач** участникам своего направления.
   - Возврат задач на доработку (`rework`) с обязательными замечаниями.
3. **Уровень 3 (Руководство медиацентра):**
   - Доступ к сводной панели `/management`.
   - Создание задач в любой цех и выдача задач любому участнику.
   - Оценивание работ (1..10 баллов) и закрытие в статус `done`.
   - Загрузка и удаление файлов в базе материалов (`/materials`).
4. **Уровень 4 (Главный администратор):**
   - Суперпользователь. Панель модерации `/admin/users`.
   - Одобрение/отклонение заявок с выставлением уровней 1..4.
   - Включение/отключение `can_create_tasks` для участников 1 уровня.
   - Редактирование профилей, сброс паролей.
   - Удаление профилей (с автоматическим освобождением их текущих задач обратно в `open`).
   - Системный аккаунт `stepyn` защищен от удаления, блокировки и деградации уровня.

---

## 🔐 Системный суперадмин (stepyn)
- **Логин:** `stepyn`
- **Пароль по умолчанию:** `admin` (также поддерживается `1111`)
- **Уровень доступа:** `4` (Главный администратор)
- Защита профиля встроена в код СУБД и API.

---

## ⚡ Производительность & SQLite WAL
- База: `server/media_app.db`
- Прагмы: WAL, synchronous=NORMAL, cache_size=-64000 (64 МБ RAM), temp_store=MEMORY, foreign_keys=ON.
- 9 индексов:
  `idx_tasks_assigned_to_id`, `idx_tasks_status`, `idx_tasks_direction`, `idx_tasks_deadline`, `idx_task_comments_task_id`, `idx_work_materials_direction`, `idx_users_role`, `idx_users_is_approved`, `idx_users_access_level`.
- Отсутствие N+1 запросов: агрегаты и связи выгружаются едиными `LEFT JOIN`.
- Атомарный пересчет KPI (`completed_tasks` и `average_score`) через вложенные подзапросы в СУБД.
- In-memory кэш сессий `userCache` (15 секунд TTL) с моментальной инвалидацией при мутациях.
- Шторка онлайна: порог 5 минут, троттлинг записи в базу 2 минуты.

## 🚀 Быстрый старт

### Вариант 1: Запуск через batch-скрипт
Дважды кликните на `start_local.bat` в папке проекта.

### Вариант 2: Запуск через терминал
```bash
# 1. Сборка Vue 3 фронтенда
npm run build

# 2. Запуск Express сервера
node server.js
```
Откройте в браузере: `http://localhost:8000`

### Вариант 3: Режим разработки (HMR)
```bash
# Терминал 1: Express API бэкенд
node server.js

# Терминал 2: Vite Dev Server с горячей заменой модулей
npm run dev:client
```
Откройте в браузере: `http://localhost:5173` (все запросы к `/api` проксируются на бэкенд).
