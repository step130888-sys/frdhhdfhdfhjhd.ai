# Правила работы с проектом Kedr Media

## КРИТИЧЕСКОЕ ПРАВИЛО: Сохранность данных (Профили и Задачи)
- **НИКОГДА** не удалять, не модифицировать и не очищать профили пользователей (`users`), задачи (`tasks`), связанные с ними комментарии и другие пользовательские данные в базе данных — ни локально, ни на удаленном сервере.
- Пользователь управляет профилями и задачами **исключительно самостоятельно**.
- При запросах на очистку разрешено трогать **ТОЛЬКО НЕ НУЖНЫЕ файлы** (временные тестовые скрипты, временный кэш, мусорные файлы в файловой системе), не затрагивая данные пользователей и задачи.
